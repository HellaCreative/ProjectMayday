# DIRT
<!-- impeccable:product-schema 1 -->

## Platform
ios

## Users
Riders planning and following road and dirt rides, alone or in groups.

## Product Purpose
Plan enjoyable rides with fuel stops, then follow them on a map. The user is currently qualifying Atlantic Canada routing on an iPhone named White.

## Capabilities and Constraints
From Here, Loop, multi-waypoint planning, saved routes, navigation, adjustable fuel and ride preferences, downloaded packs, and groups with rider location sharing. Loop starts and ends at current location and takes direction, distance and surface. Fuel replacement is accepted and frozen. National engine expansion is paused. No simulators, device installations or production publication for design exploration.

## Brand Commitments
DIRT name and orange identity. Existing wordmark size stays unchanged. DEV marks development; PRO requires active subscription in production, FREE otherwise. User likes compact icon/title planning tabs and wants bolder, sophisticated, coherent interfaces. Groups should prioritize riders; invite code is secondary and own sharing control belongs with own rider row. HTML alternatives requested before choosing the next native visual direction.

## Evidence on Hand
User screenshots and diagnostic logs in Downloads; implementation in Dirt/Features. Routing authority remains docs/00-PRODUCT-AND-ROUTING-SOURCE-OF-TRUTH.md. Prototype riders and metrics must be labelled illustrative.

## Open Decisions
Open Terrain was selected for Groups and Loop; extending its HTML preview across sheets is in progress before native implementation. Threshold for optional short dirt excursions: user mentioned both 1 km and 500 m; proposed default 1 km, retaining necessary connectors and required waypoint/fuel access.
