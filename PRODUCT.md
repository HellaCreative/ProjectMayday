# DIRT
<!-- impeccable:product-schema 1 -->

## Platform
ios

## Users
Riders planning and following road and dirt rides, alone or in groups.

## Product Purpose
Plan enjoyable rides, then follow them on a map. Routing goals, fuel behavior, qualification, and current engineering work are defined in [the routing source of truth](docs/ROUTING-SOURCE-OF-TRUTH.md).

## Capabilities and Constraints
From Here, Loop, multi-waypoint planning, saved routes, navigation, adjustable fuel and ride preferences, downloaded packs, and groups with rider location sharing. Routing behavior and engineering boundaries are defined only in [the routing source of truth](docs/ROUTING-SOURCE-OF-TRUTH.md). Design exploration does not itself authorize simulators, device installations, or production publication.

## Brand Commitments
DIRT name and orange identity. Existing wordmark size stays unchanged. DEV marks development; PRO requires active subscription in production, FREE otherwise. User likes compact icon/title planning tabs and wants bolder, sophisticated, coherent interfaces. Groups should prioritize riders; invite code is secondary and own sharing control belongs with own rider row. HTML alternatives requested before choosing the next native visual direction.

## Evidence on Hand
User screenshots and diagnostic logs in Downloads; implementation in Dirt/Features. Routing authority is [docs/ROUTING-SOURCE-OF-TRUTH.md](docs/ROUTING-SOURCE-OF-TRUTH.md). Prototype riders and metrics must be labelled illustrative.

## Open Decisions
Open Terrain was selected for Groups and Loop; extending its HTML preview across sheets is in progress before native implementation. Routing decisions and any unresolved routing questions belong only in [the routing source of truth](docs/ROUTING-SOURCE-OF-TRUTH.md).
