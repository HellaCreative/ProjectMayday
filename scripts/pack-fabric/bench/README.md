# Routing benchmark index

This directory contains benchmark runners, fixtures, and recorded results.
The existing Nova Scotia runner is exposed as `npm run bench:ns`; its comparison
option is `npm run bench:ns -- --compare <sha>`.

Current acceptance criteria, test selection, resource limits, baseline identity,
and interpretation of historical results are defined only in
[the routing source of truth](../../../docs/ROUTING-SOURCE-OF-TRUTH.md).
